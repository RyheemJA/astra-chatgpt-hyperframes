## 🛠️ Troubleshooting Common Issues

If something isn't working right, don't panic. Here are simple fixes:

### The Folder Won't Extract
- Make sure you have enough free space on your hard drive.
- Try extracting to a different location, like your Desktop.
- Ensure no antivirus software is blocking the extraction.

### I Can't See Any Images or Videos
- All assets are standard image and video files (.png, .jpg, .mp4).
- Make sure you're opening them with a default Windows app like **Photos** or **Movies & TV**.
- If they still won't open, try right-clicking > **Open With** and choose another app.

### ChatGPT Says My Prompt Is Invalid
- Copy the text exactly as it is. Don't add extra words.
- Make sure you're not missing any part of the prompt (they can be long).
- Try breaking the prompt into smaller sentences if it's very long.

### Nothing Happens When I Click the Download Link
- Check your internet connection.
- Try a different browser (Chrome, Edge, Firefox).
- Disable pop-up blockers temporarily.
- The page might be temporarily down; wait a few minutes and try again.
